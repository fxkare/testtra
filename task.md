# Görev Listesi: Anında Çeviri Uygulaması

- [ ] `requirements.txt` dosyasını oluştur (Gerekli kütüphaneler: customtkinter, keyboard, pyperclip, deep-translator).
- [ ] `translator_app.py` dosyasını oluştur.
    - [ ] `Ctrl+Alt+T` dinleyicisini ekle.
    - [ ] Seçili metni otomatik kopyalamak için `Ctrl+C` simülasyonu ekle.
    - [ ] Panodan metni çekip `deep-translator` ile Türkçe'ye çevir.
    - [ ] Çeviriyi şık bir `customtkinter` penceresinde (popup) göster.
    - [ ] ESC tuşu veya pencere dışı etkileşimle pencerenin kapanmasını sağla.
- [ ] Kütüphaneleri kur (`pip install -r requirements.txt`).
- [ ] Uygulamayı test et ve kullanıcıya çalıştırılması için bilgi ver.
